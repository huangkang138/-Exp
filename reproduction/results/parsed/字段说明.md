# `all_runs.csv` 字段说明

`all_runs.csv` 是供统计和绘图脚本读取的机器数据表。**每一行代表某个 MSTSP 实例的一次独立运行**。

不要直接修改第一行英文列名，否则 `calculate_metrics.py` 和绘图脚本可能无法识别字段。

## 基本信息

| 英文字段 | 中文含义 | 怎么看 |
|---|---|---|
| `instance` | 测试实例编号 | 例如 `MSTSP1`、`MSTSP25` |
| `type` | 实例类型 | `Simple` 简单型、`Geometry` 几何型、`Composite` 复合型 |
| `city_count` | 城市数量 | 数量越大，通常问题越复杂 |
| `run` | 第几轮运行 | `1` 表示该实例的第1次独立运行，不是算法内部迭代次数 |
| `seed` | 随机种子 | 固定随机过程，便于复现同一次运行；数值大小不代表效果好坏 |

## 算法输出

| 英文字段 | 中文含义 | 怎么看 |
|---|---|---|
| `route` | 一条代表性最优路线 | 这里只保存输出文件中的第一条路线，完整路线集合要看 `output_file` |
| `route_cost` | 最优路线代价 | 当前输出文件中最小的路线长度；越小越好，但不同实例之间不宜直接横向比较 |
| `number_of_solutions` | 本轮输出的最优路线数量 | 表示 `.alg_solution` 文件中的路线条数；规范化去重后的数量可能与它不同 |
| `Fbeta` | Fβ 指标 | 衡量真实最优路线是否找得准、找得全，范围0～1，越接近1越好 |
| `DI` | 多样性指标 | 衡量返回路线对真实最优路线结构的覆盖程度，范围0～1，越接近1越好 |
| `elapsed_seconds` | 本轮运行时间 | 单位为秒 |

## 实验参数

| 英文字段 | 中文含义 | 怎么看 |
|---|---|---|
| `MaxFes` | 最大适应度评价次数 | 算法的搜索预算，不是秒数，也不是运行轮数 |
| `NP` | 论文中的种群规模参数 | 当前 Python 实现没有确认等价参数，所以为空；不要把空值理解成0 |
| `antNum` | 蚂蚁数量 | 当前为150，表示每轮搜索参与构造路线的蚂蚁数量 |
| `alpha` | 信息素权重 | 当前为1.0，控制历史信息素对选路的影响 |
| `beta` | 启发式信息权重 | 当前为1.5，控制距离等启发式信息对选路的影响 |
| `rho` | 信息素蒸发系数 | 当前为0.3，控制旧信息素衰减速度 |

注意：表中的算法参数 `beta=1.5` 与评价指标 `Fbeta` 不是同一个参数。Fβ 指标计算使用的是 `β²=0.3`。

## 运行状态和证据文件

| 英文字段 | 中文含义 | 怎么看 |
|---|---|---|
| `exit_code` | 程序退出码 | `0` 表示正常完成；非0表示运行失败；超时可能为空 |
| `output_file` | 算法结果文件 | 保存本轮找到的全部路线，是计算 Fβ 和 DI 的直接依据 |
| `stdout_file` | 标准输出日志 | 查看算法正常打印的信息，例如最优代价和解数量 |
| `stderr_file` | 错误输出日志 | 查看错误或警告；正常运行时通常为空 |

## 示例：MSTSP1 这一行是什么意思

```text
instance=MSTSP1
type=Simple
city_count=9
run=1
seed=7
route_cost=680
number_of_solutions=3
Fbeta=1.0
DI=1.0
elapsed_seconds≈5.10
exit_code=0
```

可以读成：

> MSTSP1 是一个9城市的简单型实例。本次是第1轮运行，使用随机种子7。算法约运行5.10秒，找到3条最优路线，最优路线代价为680。Fβ和DI均为1，且退出码为0，说明本轮正常完成并完整覆盖了标准答案。

更完整的实验参数解释见项目根目录的 `实验配置与参数说明.md`。
