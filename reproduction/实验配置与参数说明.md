# GB-MACO 实验配置与参数说明

这份文档只解释“实验是怎样运行的、每个参数有什么作用”。结果含义和论文公式请分别查看 `results/` 与 `paper_notes.md`。

## 1. 当前这次实验实际用了什么

实际参数以每轮目录中的 `metadata.json` 为准。当前已有结果的配置是：

| 项目 | 当前值 | 含义 |
|---|---:|---|
| 参数档位 | `source_original` | 使用当前公开 Python 源码的实际参数，不冒充严格论文参数 |
| 实例 | MSTSP1～MSTSP25 | 共25个测试实例 |
| 运行轮数 | 每个实例1轮 | 只能表示一次运行结果，不能统计稳定性 |
| MaxFes | MSTSP1～12：60000；MSTSP13～25：1200000 | 每轮允许的最大适应度评价次数 |
| antNum | 150 | 每轮搜索使用的蚂蚁数量 |
| alpha | 1.0 | 信息素对选路的影响强度 |
| beta | 1.5 | 距离等启发式信息对选路的影响强度 |
| rho | 0.3 | 信息素蒸发系数 |
| 信息素更新比例 | 0.3 | 每轮参与信息素强化的候选比例 |
| 最大信息素矩阵数 | 9 | 多群体搜索最多维护的信息素矩阵数量 |
| 单轮超时 | 3600秒 | 一轮超过1小时会被判为超时 |

当前结果都使用显式随机种子。MSTSP2～MSTSP25 的种子分别为2～25；MSTSP1保留了较早单独运行产生的种子7。批量续跑跳过了已经成功的结果，因此不会自动重写这个旧种子。

## 2. 随机种子 seed 是什么

蚁群算法包含随机选路。同一套数据和参数即使不改代码，多运行几次也可能找到不同数量的最优路线。

随机种子用于固定随机数序列：

- 相同代码、参数和种子：便于复现同一次实验。
- 不同种子：用于观察算法在不同随机情况下是否稳定。
- 种子只是实验编号，不存在“种子越大效果越好”。

例如 `--seed-start 1` 表示从种子1开始，后续任务依次使用2、3、4……。如果每个实例运行30轮，每轮应该使用不同种子，最后再计算均值和标准差。

## 3. runs（运行轮数）是什么

`runs` 表示每个实例独立运行多少次，不是算法内部迭代次数。

- `runs=1`：每个实例只运行一次，速度较快，但结果可能受随机性影响。
- `runs=30`：每个实例独立运行30次，可以计算均值、标准差、最好值和最差值。

当前结果是 `25个实例 × 1轮 = 25轮`。因此图中的结果属于单次全量测试，不是30轮统计实验。

## 4. MaxFes 是什么

`MaxFes` 是最大适应度评价次数，可以理解为算法的主要搜索预算。每评价一条候选路线，都需要消耗评价次数。

- 数值越大：搜索机会更多，但运行时间通常更长。
- 数值越小：运行更快，但可能来不及找到全部最优路线。

它不是运行秒数，也不是循环次数。不同实例使用不同 MaxFes，是为了给复杂实例更大的搜索预算。

## 5. 蚁群算法参数

### antNum = 150

每一代参与构造路线的蚂蚁数量。更多蚂蚁能够同时探索更多路线，但也会增加计算量。

### alpha = 1.0

信息素权重。它决定算法有多相信历史搜索积累的信息素。数值过大容易让搜索过早集中到少数路线。

### beta = 1.5

启发式信息权重。它决定算法有多偏向距离更短、当前看起来更有利的下一步。

这里的算法参数 `beta=1.5` 与评价指标 `Fβ` 中的 β 不是同一个东西。项目计算 Fβ 时使用的是 `β²=0.3`，两者不要混淆。

### rho = 0.3

信息素蒸发系数。蒸发用于逐渐削弱旧经验，避免算法一直被早期路线支配。

### pheromone_update_percentage = 0.3

控制每轮有多少比例的候选结果参与信息素强化，影响优秀路线经验的传播速度。

### tau0

初始信息素强度。当前实现根据蚂蚁数量和贪心初始路线长度自动计算：

```text
tau0 = antNum / 贪心路线长度
```

它不是手工填写的固定常数。

## 6. profile（参数档位）

### source_original

当前可运行档位，表示按照 Python 源码现有实现和参数运行。这次实验使用的就是该档位。

### paper_setting

记录论文参数，但当前被标记为 `unverified`，不能直接运行。主要原因是：

- 论文对 MSTSP13～25 使用 `NP=300`，Python 源码没有与它明确等价的 `NP` 参数。
- 论文的自适应 `msize=2～9` 与 Python 中信息素矩阵数量2～9含义不同。
- Python 的候选解 archive 维护方式与论文文字描述也不完全相同。

因此当前结果可以称为“Python 公开实现的复现实验”，不能写成“完全按照论文参数复现”。

## 7. timeout（超时）

当前每轮最多运行3600秒。超时只是实验保护措施，不会提高或降低算法性能。

- 正常完成：`timed_out=false`、`exit_code=0`。
- 超时：该轮不会被当作正常成功结果参与汇总。

## 8. 去哪里确认实际参数

不同文件的可信用途如下：

1. `results/raw/MSTSP*/run_*/metadata.json`：某一轮真正使用的参数，最权威。
2. `results/raw/batch_summary.json`：整个批次请求了哪些实例、轮数以及成功/失败情况。
3. `config/experiment_config.json`：默认配置和实例映射。
4. `results/parsed/all_runs.csv`：整理后的逐轮结果和参数。

判断实验时，不要只看命令或默认配置；最终应以每轮 `metadata.json` 保存的实际参数为准。

## 9. 当前结果可以怎样表述

推荐写法：

> 在 `source_original` 参数档位下，对25个 MSTSP 实例分别进行1次显式随机种子实验，并使用论文定义的 Fβ 和 DI 指标评价 Python 实现的单次运行结果。

不建议写成：

> 完全使用论文参数完成30次重复实验。

因为当前既不是严格论文参数，也不是每个实例30轮。
