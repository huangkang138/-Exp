# GB-POMO Dataset v1

用于当前 `粒球 + Attention + POMO` 路径规划实验的训练/验证数据。

## 数据划分

- `train/`：5000 个训练实例
  - 5 个城市规模：10 / 20 / 30 / 50 / 60
  - 2 种空间分布：uniform / clustered
  - 每个“规模 × 分布”500 个实例
- `validation/`：1000 个固定验证实例
  - 每个“规模 × 分布”100 个实例
- 原项目 `benchmark_MSTSP` 的论文算例不要混入这里，建议保留为最终测试集。

## 文件格式

每个 `.tsp` 文件只包含城市二维坐标，一行一个城市：

```text
223 184
517 902
...
```

这与当前项目 `read_cities()` 所需的“每行 x y”格式一致。

## 两类分布

### uniform

城市在 `[0, 10000] × [0, 10000]` 平面上独立均匀生成。

用途：训练一般的二维 TSP 空间关系。

### clustered

先随机生成多个聚簇中心，再围绕中心按高斯分布生成城市。

用途：让数据中出现明显局部簇结构，更适合检验粒球预处理是否真正提供帮助。

不同城市规模使用不同聚簇数范围：

- n=10：2~3 个簇
- n=20：2~4 个簇
- n=30：3~5 个簇
- n=50：4~6 个簇
- n=60：4~7 个簇

## 训练建议

训练时：

1. 只读取 `train/`
2. 每个 batch 内保持相同城市数 N
3. uniform 与 clustered 都参与训练
4. 不要使用 validation 更新参数

验证时：

1. 使用 `validation/`
2. 固定这些实例，不重新生成
3. 记录平均路线长度、best route、相对基线差距等指标

最终测试时：

1. 使用原 `benchmark_MSTSP`
2. 与原 GB-MACO 在完全相同实例上比较
3. 原 benchmark 不参加训练和模型选择

## 文件说明

- `manifest.csv`：每个实例的 split、规模、分布、随机种子、文件路径和 SHA256。
- `dataset_config.json`：完整生成参数。
