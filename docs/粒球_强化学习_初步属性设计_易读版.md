# 粒球 + 强化学习初步属性设计

## 1. 粒球构造属性

用于描述城市本身的特征：

**城市特征 = 坐标 + 消费水平 + 城市舒适度**

`Xᵢ = (xᵢ, yᵢ, costLevelᵢ, cityComfortᵢ)`

- `xᵢ, yᵢ`：城市坐标
- `costLevelᵢ`：城市消费水平
- `cityComfortᵢ`：城市舒适度

**作用：** 根据空间位置和城市属性进行多属性粒球划分。

---

## 2. 强化学习路径属性

用于描述城市之间的通行情况：

**路径属性 = 距离 + 通行费用 + 通行时间 + 通行舒适度**

`Eᵢⱼ = (distanceᵢⱼ, travelCostᵢⱼ, timeᵢⱼ, travelComfortᵢⱼ)`

- `distanceᵢⱼ`：城市 i 到城市 j 的距离
- `travelCostᵢⱼ`：城市 i 到城市 j 的通行费用
- `timeᵢⱼ`：城市 i 到城市 j 的通行时间
- `travelComfortᵢⱼ`：城市 i 到城市 j 的通行舒适度

**作用：** 用于强化学习 Reward，决定下一步路径选择。

---

## 3. Reward 初步形式

第一版采用加权综合评价：

`Reward = −(距离代价 + 费用代价 + 时间代价) + 舒适度奖励`

具体写为：

`Rᵢⱼ = −(w_d·Dᵢⱼ + w_c·Cᵢⱼ + w_t·Tᵢⱼ) + w_s·Sᵢⱼ`

其中：

- `Dᵢⱼ`：距离
- `Cᵢⱼ`：通行费用
- `Tᵢⱼ`：通行时间
- `Sᵢⱼ`：通行舒适度
- `w_d、w_c、w_t、w_s`：各属性权重

---

## 4. 整体流程

```text
城市坐标
+ 城市消费水平
+ 城市舒适度
        ↓
多属性粒球划分
        ↓
粒球结构
        ↓
距离 + 通行费用 + 时间 + 通行舒适度
        ↓
强化学习 Reward
        ↓
路径决策
        ↓
最终完整路线
```

### 强化学习侧
